1. Start with the reference and the changes

A photograph is a useful starting point for a custom garment brief. Name the style code, then separate the features you want to keep from the changes you want to make. This helps a color request stay separate from a new sleeve, collar or hardware design.

The 0827 and 0828 reference ranges above show several approaches. The two linked detail examples below focus on a grey fox-fur-trim lapel jacket and a green leather biker jacket with rex rabbit fur trim. Use the front, back and angled photographs on each detail page to discuss the silhouette, trim placement and visible construction.

2. Specify the body, trim and lining separately

Use a separate line for each part of the garment. A surface description such as suede-look or textured leather is useful for discussing appearance, but it does not provide a fiber percentage or identify a leather species. For your project, record the material you choose and keep that choice consistent through the sample review.

PartWhat to include in your brief
BodyMaterial direction, color, surface finish and the composition or leather type you require.
Fur trimFur type, color, placement and the areas to be covered.
LiningMaterial and color preference, plus any required label information.
ConstructionCollar, sleeve, closure, belt and pocket details to keep or change.

3. Choose size labels or custom measurements

Send the intended size labels together with target finished-garment measurements or a brand size chart. Feasibility and grading are confirmed in writing for the selected style and material. A letter label by itself is not a finished-garment specification.

If you already have measurements, include the unit and explain whether each measurement describes the body or the finished garment. Useful points to discuss include chest, shoulder, sleeve and back length, together with the space you want for layering. No universal measurement numbers are assigned to these reference styles.

4. Separate custom sizing and basic options from structure changes

For the reference styles linked in this guide, colors, sizes, body materials, fur, lining, labels and packaging can be customized under a project-specific MOQ. Collar or sleeve structure changes and hardware customization require a project-specific structural-change threshold. These minimums are counted across the whole order, rather than adding a separate minimum for each color or size.

Provide your label artwork, placement preference and packaging direction with the brief. If you want a part to be removable, state that request explicitly; a photograph alone does not establish that the reference garment already has a removable construction.

5. Plan the sample and quantity-dependent production

For these references, The sample target date and production schedule are confirmed in writing after style, material, quantity and specification review. The agreed start condition is recorded for the selected project. Share your order quantity and required delivery date when discussing the production schedule; there is no single fixed bulk lead time shown here.

Keep the chosen material, dimensions, color and branding notes with the sample review so the intended garment is clear. For care, home washing or machine washing is not recommended. If cleaning is needed, consult a professional fur-care specialist and follow the requirements for the actual mixed materials.

6. Send a concise inquiry

  • Reference style code or your own design.
  • Order quantity and color allocation.
  • Standard size labels, your size chart or custom measurement direction.
  • Body material, fur, lining and any construction changes.
  • Label artwork, packaging preference and destination.

These notes give the conversation a clear starting point without treating a reference image as a complete technical specification.

7. Questions buyers are asking now

Can a photograph confirm the fur category?

No. A photograph can show length, color, placement and visible texture, but it cannot reliably prove a species or material subtype. Use supplier records, labels and the approved project specification.

How should a dyed or color-block fur direction be approved?

Approve the material category first, then confirm a physical color reference, placement map and sample under agreed viewing conditions. Mixed materials may react differently, so the body, fur, backing and lining must be reviewed together.

What should a knitted fur cardigan specification include?

Record the knitted-base composition, fur category, attachment direction, lining or unlined construction, closure, finished measurements and color placement before sampling.

Should every color have a separate page?

No. When the construction and buyer intent are the same, keep the colors on one canonical page. Create a separate page only when length, collar, cuffs, closure, body construction or another meaningful specification changes.
